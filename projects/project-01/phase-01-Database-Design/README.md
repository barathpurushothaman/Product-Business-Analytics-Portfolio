# Phase 02 - Database Design

**Project:** Olist E-Commerce Business Analysis

**Status:** 🚧 In Progress

**Tools Used:** PostgreSQL, pgAdmin, SQL

---

## Objective

Design and implement a relational database from the raw Olist CSV files.

The focus of this phase is to build a reliable database that supports accurate business analysis.

---

## Activities

- Create PostgreSQL database
- Design relational schema
- Create tables
- Define primary keys
- Define foreign keys
- Import CSV datasets
- Validate imported data
- Verify record counts

---

## Deliverables

- Database Schema
- SQL DDL Scripts
- Import Validation Queries
- Database Documentation

---

## Success Criteria

- All datasets imported successfully
- Relationships established
- Record counts validated
- Database ready for analysis
